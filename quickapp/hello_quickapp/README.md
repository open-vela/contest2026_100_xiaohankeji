# 小涵打砖块 (Xiaohan Brick Breaker)

> **一款基于 openvela 快应用框架开发的手表体感微运动游戏**
> *"我相信，运动不该有门槛。不是所有的运动，都得大汗淋漓。只要开始动，就值得被看见！"*

## 📖 项目简介

**小涵打砖块** 是一款专为智能手表（基于 openvela 操作系统）打造的体感游戏。项目旨在解决传统手表游戏“屏幕小、手指遮挡、久坐不动”的痛点，摒弃触屏点按，采用 **IMU（惯性测量单元）体感操控**。玩家通过倾斜手腕控制挡板，在碎片化时间内完成一局60秒的解压游戏。

同时，游戏结合了**健康微运动**理念，在结算页及累计数据中展示游玩时长、焦耳（J/kJ）消耗热量及手腕摆动次数，让每一次娱乐都变成一次真实的轻运动。

## ✨ 核心亮点

- **🕹️ 纯端侧体感交互**：基于 `system.sensor` 订阅加速度计，采用“一阶低通滤波 + 死区处理 + 比例映射”的三级数据处理链，端到端延迟 < 50ms，实现丝滑跟手。
- **🎮 四大原创玩法**：
  - **狂野模式**：底层动态移动砖块，考验极限预判。
  - **血量模式**：红砖扣血、绿砖回血，考验生存策略。
  - **极限模式**：高密度阵型，高难度挑战。
  - **繁殖模式**：小球裂变，满屏弹射，极其解压。
- **⚡ 极致性能与体积**：针对 466×466 圆形表盘深度适配，全量代码打包 `.rpk` 体积 **< 100KB**，无惧内存溢出，连续运行极度稳定。
- **🛡️ 高可靠容错机制**：内置“手动体感校准”解决陀螺仪漂移；支持体感/触屏双模硬切换；生命周期严格管理（onDestroy 清理定时器与传感器），防止内存泄漏。
- **🤖 AI-Native 开发**：沉淀了专属的 `陀螺仪控制` 与 `2D物理引擎` Skill，大幅提升 AI 辅助开发效率。

## 🛠️ 技术架构

项目采用**端侧四层架构**，不依赖云端，断网亦可无缝游玩：

1. **应用层（UI）**：openvela 快应用 `.ux` 页面，Canvas 渲染。
2. **逻辑层（Game Core）**：35ms/帧主循环，小球运动积分、AABB 碰撞检测、状态机与三级体感处理链。
3. **硬件抽象层（HAL）**：调用 `system.sensor`、`system.storage`、`system.router`、`system.device` 等标准 API。
4. **系统层（OS）**：openvela OS 驱动管理与任务调度。

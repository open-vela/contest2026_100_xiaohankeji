# 小涵打砖块

## 一、作品简介

小涵打砖块是一款基于 openvela 快应用框架开发的手表体感游戏。用户通过倾斜手腕控制挡板左右移动，将小球击碎砖块。游戏结束后会根据游戏时长和手腕活动量，实时估算并展示本次游戏消耗的热量，让用户在碎片化时间内完成一次“手腕微运动”。

本项目解决的是手表端缺少沉浸式娱乐内容、触屏操作体验差、缺乏“娱乐+健康”结合应用的三个痛点，为穿戴设备提供了一种新的体感交互范式。

## 二、选题方向

**手表应用创新**

本项目围绕智能手表/手环的典型使用场景（碎片化时间、小屏幕、手腕佩戴），设计了一款充分利用设备特性的体感游戏。通过调用手表 IMU 传感器实现姿态控制，验证了体感交互在手表端的可行性与用户体验优势，属于面向可穿戴设备的应用创新。

3. 编译打包
   - 在 AIoT-IDE 中打开项目
   - 点击「构建」按钮，生成 .rpk 安装包

4. 部署到真机
   - 使用数据线连接手表与电脑
   - 在 AIoT-IDE 中点击「运行」，选择已连接的设备
   - 应用将自动安装并启动
   -（或使用第三方安装工具将 .rpk 包推送到手表）

5. 开始游戏
   - 手表上点击「小涵打砖块」图标
   - 倾斜手腕控制挡板，击碎所有砖块即可过关

## 五、AI Coding 使用说明

本作品在开发过程中深度借助 AI 辅助完成，形成了"需求描述 → AI 生成 → 真机验证 → 反馈修正"的协作模式。

各环节 AI 使用情况：

需求拆解：描述游戏玩法，AI 帮助拆解为模块清单（UI、物理引擎、体感控制、数据持久化），快速明确开发范围，避免遗漏

方案设计：询问技术选型（传感器 API 调用方式、滤波算法选型），AI 提供了滤波方案对比，帮助确定一阶低通滤波 + 死区的三级处理链

UI 搭建：描述界面需求，AI 生成 .ux 文件中的 <template> 结构，大幅减少重复性布局代码编写时间

传感器 API 调用：让 AI 生成 system.sensor 订阅代码模板，快速获得可运行的样板代码，加速功能集成

物理引擎：AI 生成 AABB 碰撞检测逻辑，自己修正边界条件，先获得可用版本，再根据实测结果优化边缘情况

调试：将编译/运行时的报错信息直接粘贴给 AI，快速定位错误原因（如权限声明缺失、生命周期管理遗漏）

文档编写：AI 辅助生成技术报告框架和 Skill 说明，提升文档编写效率，保证结构完整

AI 对开发效率的实际提升：
- 将重复性编码工作（布局、样板代码）从数小时缩短到数十分钟
- 通过 AI 快速验证算法方案，减少了从零搜索和试错的时间
- 报错时 AI 能快速指出问题方向，缩短了排查时间

完整 AI 对话日志见仓库 logs/ 目录。
